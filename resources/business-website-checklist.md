# Business Website Checklist

Before launching a business website, check the following.

## Design

- [ ] Mobile responsive
- [ ] Clear navigation
- [ ] Professional branding
- [ ] Strong calls to action
- [ ] Fast-loading images

## Content

- [ ] About page
- [ ] Services/products
- [ ] Contact information
- [ ] Business location
- [ ] FAQs
- [ ] Privacy information

## SEO

- [ ] Page titles
- [ ] Meta descriptions
- [ ] Heading structure
- [ ] Image alt text
- [ ] Internal links
- [ ] Sitemap
- [ ] Robots.txt
- [ ] Google Search Console
- [ ] Google Business Profile

## Conversion

- [ ] Phone number
- [ ] WhatsApp
- [ ] Contact form
- [ ] Clear CTA
- [ ] Testimonials
- [ ] Trust signals

## Technical

- [ ] SSL
- [ ] Backups
- [ ] Analytics
- [ ] Security
- [ ] Domain ownership
- [ ] Hosting access
